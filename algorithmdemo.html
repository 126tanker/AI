What Is an Algorithm?

An algorithm is a formal, step‑by‑step procedure that transforms inputs into outputs using fixed rules. Algorithms do not think or understand—they execute instructions.

Example A: Scoring Algorithm

Inputs

Experience (years): Test Score:

Algorithm (Mathematical Form)

score = (experience × w1) + (test_score × w2)

where:
  w1 = 0.6
  w2 = 0.4

Example B: Nearest‑Neighbor Classification

Inputs

Age: Income (thousands):

Algorithm (Procedural Form)

Given labeled data points

For new input X:
  1. Compute distance
  2. Find closest point
  3. Assign its label

distance = sqrt((x1 − y1)² + (x2 − y2)²)

Key Takeaways

  • The algorithm itself never changes unless we rewrite it: Algorithms are rules, not intelligence
  • Inputs are transformed using these fixed mathematical rules
  • AI systems apply algorithms like this repeatedly and at scale
