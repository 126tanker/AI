How Text Is Processed by an Algorithm

In early and non‑AI systems, words and phrases are processed using explicit text algorithms. These algorithms do not understand language—they apply fixed rules to characters and words.

Example: Keyword‑Based Text Scoring Algorithm

Input

Enter a word or short phrase:

Algorithm (Procedural Form)

score = 0

For each word in input:
  if word is in positive_words:
      score = score + 1
  if word is in negative_words:
      score = score - 1

positive_words = {
  good, great, success, opportunity
}

negative_words = {
  bad, failure, problem, loss
}

What This Demonstrates

  • Text is treated as data, not meaning
  • The algorithm uses exact matching rules
  • Outputs depend entirely on predefined logic
  • Modern AI replaces rules with learned parameters
